# Hi, I'm Carlos Velásquez 👋

**Backend-leaning full-stack engineer.** I build and run production web platforms: Go and Ruby on Rails services, React/Next.js frontends, containers and cloud infrastructure.

## What I do

- 🏗️ **APIs & microservices** — Go (Gin, GORM) and Rails services, background jobs, queues, caching, auth (JWT, OAuth, WebAuthn).
- 🖥️ **Frontends** — React, Next.js, TypeScript, Vite, Tailwind.
- ☁️ **Infra** — Docker, Kubernetes, Traefik, Redis, Postgres/MySQL, AWS and Oracle Cloud.
- 🤖 **Automation & AI** — Telegram bots, scrapers, data pipelines and LLM-assisted workflows running on schedules.
- 🔌 **Hardware & integrations** — scale/serial data capture in Go and Python, Microsoft Graph, Google auth, third-party sports and device APIs.
